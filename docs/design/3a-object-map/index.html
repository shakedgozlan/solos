How it all fits

  1. You talkA note: voice or pasted text, kept as it was.
  2. Sol sortsTurns it into moments: minutes, mood, progress, a task done.
  3. Things growEach moment adds to something lasting: a goal, a topic, a task.
  4. Sol gives backToday, recall, the map, Saturday's review, About you.

Screens are only windows onto these things. That's why one note can update several apps at once, and why changing one thing changes it everywhere.
